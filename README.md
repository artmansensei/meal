# খাবার হিসাব — PWA

বাংলা ভাষায় তৈরি একটি minimal, responsive, offline-first খাবার ও পেমেন্ট হিসাব অ্যাপ।

## ফিচার
- তারিখ অনুযায়ী দুপুর/রাতের মিল চেক করা
- প্রতি মিলের দাম ৳৬০ ধরে খরচ গণনা
- টাকা জমার তারিখ, পরিমাণ ও নোটসহ ইতিহাস
- মোট মিল, মোট খরচ, মোট জমা, বাকি/অগ্রিম হিসাব
- Dark/Light mode
- CSV export
- Local storage এবং service worker cache; ইনস্টলযোগ্য PWA

## চালানোর নিয়ম
`index.html` ব্রাউজারে খুলে ব্যবহার করতে পারবেন। PWA install/offline caching পুরোপুরি পরীক্ষা করতে HTTPS hosting বা localhost ব্যবহার করুন।

## গুরুত্বপূর্ণ
ডেটা এই ব্রাউজারের localStorage-এ থাকে। ব্রাউজারের data clear করলে বা অন্য ডিভাইসে গেলে ডেটা স্বয়ংক্রিয়ভাবে যাবে না। নিয়মিত CSV export করে ব্যাকআপ রাখুন।
